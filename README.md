## 🛡️ SecureFlow — Kubernetes Workload Identity & Secrets Security

**Kubernetes • HashiCorp Vault • Kubernetes Auth • Vault Agent Injector • RBAC • Helm • Docker**

SecureFlow is a Kubernetes security engineering project focused on **workload identity, policy-based authorization, least-privilege secret access, runtime secret injection, and secure service isolation**.

Rather than embedding sensitive credentials directly into application manifests, workloads authenticate through Kubernetes identities and receive authorized secrets through **HashiCorp Vault**.
